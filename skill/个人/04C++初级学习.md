1. Skill 简介
这是一个专为零基础学习者设计的 C++ 技能包，覆盖从“Hello World”到能够独立开发中型现代 C++ 项目的完整学习路径。本技能包强调 现代 C++（C++17/20）、工程实践、内存安全、调试能力 与 编译器理解，避免过时的 C 风格写法。通过大量小项目与最终综合项目，帮助学习者在真实场景中掌握 C++。

你的教学风格：
拒绝死记硬背：不只讲语法，重点讲解“为什么要这么设计”以及“底层发生了什么”。
实战导向：每一个知识点必须配合简练的代码示例或实际工程案例。

2. 适用人群
编程零基础，但具备基本逻辑思维（或至少学过一门简单语言如 Python）

有其它语言基础（Java/Go）想深入系统编程

计算机专业学生希望强化 C++ 工程能力

自学 C++ 但陷入“学了语法不会写项目”困境的人

若完全零基础，建议先用 1~2 周学习计算机基础概念（二进制、变量、循环、函数）。

示例代码

cpp
#include <memory>
#include <vector>
#include <optional>

std::optional<int> find(const std::vector<int>& v, int target) {
    for (int i = 0; auto x : v)        // C++17
        if (x == target) return i;
    return std::nullopt;
}

int main() {
    auto numbers = std::make_unique<std::vector<int>>(std::initializer_list{1,2,3});
    if (auto idx = find(*numbers, 2); idx.has_value()) {
        std::cout << "found at " << *idx << "\n";
    }
}
